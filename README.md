# smart khuzestan heritage navigator (میراث‌یاب هوشمند خوزستان) 
##**بهینه‌سازی مسیرهای گردشگری میراث فرهنگی با هوش مصنوعی**




## مقدمه

سامانه‌ای وب‌محور است که با بهره‌گیری از الگوریتم‌های یادگیری ماشین و بهینه‌سازی مسیر، برنامه‌ریزی مسیرهای گردشگری یک‌روزه را در استان خوزستان تسهیل می‌کند. این پروژه با تمرکز بر **میراث مادی (سایت‌های باستانی ثبت‌شده در یونسکو)** و **میراث ناملموس (صنایع دستی محلی)**، ابزار قدرتمندی برای گردشگران، تورلیدرها و سازمان‌های میراث فرهنگی فراهم می‌آورد.

این سامانه برای **بخش میراث دیجیتال** چهارمین جشنواره بین‌المللی چندرسانه‌ای میراث فرهنگی توسعه یافته و **جایزه ویژه خوزستان** را هدف قرار داده است.

این سامانه با استفاده از هوش مصنوعی، مسیرهای کوتاه و کم‌هزینه را طراحی می‌کند تا هم مصرف سوخت کاهش یابد و محیط زیست محوطه‌های تاریخی حفظ شود، و هم درآمد فصلی مکان‌ها از بلیط و فروش صنایع دستی پیش‌بینی و به حداکثر برسد.
در عمل، این ابزار به گردشگران کمک می‌کند سفری هوشمند و پربار داشته باشند، به تورلیدرها امکان برنامه‌ریزی دقیق می‌دهد، و برای سازمان میراث فرهنگی داده‌های ارزشمندی از الگوهای بازدید فراهم می‌آورد تا سیاست‌گذاری بهتری انجام شود.
**فایده اقتصادی**: تقویت درآمد محلی از بلیط و صنایع دستی، حمایت از کسب‌وکارهای سنتی، ایجاد زنجیره ارزش گردشگری پایدار و افزایش قدرت خرید گردشگران در بازارهای محلی.
**هدف محیطی**: کاهش مسافت پیموده‌شده، صرفه‌جویی در سوخت و حفاظت از محوطه‌های تاریخی در برابر آلودگی.
اکوسیستم گردشگری و میراث فرهنگی: ایجاد ارتباط زنده بین گردشگر (تجربه بهتر و آگاهانه)، محل‌های تاریخی (بازدید هدفمند)، صنایع دستی (فروش مستقیم) و جامعه محلی (درآمد و حفظ هویت)، تا میراث نه فقط حفظ شود، بلکه زنده و پویا بماند.

## ویژگی‌های کلیدی
- **دو مدل پیش‌بینی سود**: محاسبه سود کل سالانه و سود فصلی با استفاده از **Random Forest** و **SMOTE** برای تعادل داده‌ها.
- **بهینه‌سازی مسیر**: الگوریتم **TSP** با **OR-Tools** برای یافتن کوتاه‌ترین مسیر.
- **نقشه تعاملی**: نمایش مسیر و نشانگرها با **Folium** و **Streamlit-Folium**.
- **انتخاب فصل سفر**: وزن‌دهی فصلی .
- **ذخیره‌سازی نتایج**: ثبت خودکار در **PostgreSQL** با زمان‌بندی.
- **رابط کاربری فارسی**: فونت **Vazir** و پشتیبانی کامل از متن راست‌به‌چپ (RTL).

## نحوه اجرا
### پیش‌نیازها
- Python 3.9+  
- PostgreSQL (پسورد پیش‌فرض: `1234567890`)

### نصب و اجرا
```bash
# ۱. کلون مخزن
git clone https://github.com/shaqayeq-B/smart-khuzestan-heritage-navigator


# ۲. نصب وابستگی‌ها
pip install -r requirements.txt
pushd (location of the file of smart-khuzestan-heritage-navigator.py)

# ۳. اجرای اپلیکیشن

streamlit smart-khuzestan-heritage-navigator.py


smart-khuzestan-heritage-navigator/
├── smart-khuzestan-heritage-navigator.py  # کد اصلی
├── Vazir-Regular.ttf                      # فونت فارسی
├── requirements.txt                       # وابستگی‌ها
├── selection1.jpg                         # اسکرین‌شات انتخاب
├── results3.jpg                           # اسکرین‌شات نتایج
├── map2.jpg                               # اسکرین‌شات نقشه
├── Demo.mp4                               # دموی  
├── LICENSE                                # پروانه                               
```
داده‌ها:
مکان‌ها: ۳۵ مورد واقعی با مختصات GPS (منابع: Google Maps، سازمان میراث فرهنگی)
سود: شبیه‌سازی منطقی (آماده جایگزینی با داده‌های واقعی)
